## 2. 과금 원칙 (철저히 지킨다)

1. **시간을 들이면 무과금도 전부 얻는다.** 유료로만 얻는 전투력은 없다.
2. **과금은 '기다림·반복'을 줄인다**: 공사 가속, 원정 슬롯, 오프라인 상한, 무료 가속, 보석.
3. **확률형은 구세계 금고 하나** — 확률 전부 화면에 공개, 천장 200점(군용 금고 5회분)이면 전설 확정, 녹슨 보급함 12시간마다 무료. 유물 칸은 생존 기록(30일·60일)으로 무료 해금.
4. **어려움 난이도는 돈으로 즉시 클리어 불가** (과금해도 90일 이상 — balance-sim 검증).
5. 미성년자 월 7만원 한도, 청약철회 7일 안내, 결제 지급은 서버(Netlify Function)에서만.

## 4. 계산 결과 요약 (자세한 표는 MONETIZATION_TABLES.md)

- **무과금 하루 1시간**: 1년 보석 약 5.5만, 무료 가속 약 650시간 → 공사 52시간을 전부 무료로 처리. VIP 3은 46일, VIP 5는 약 160일.
- **월정액만(4,900원)**: VIP 5가 약 96일로 무과금보다 2개월 빠름. 보석은 무과금의 약 1.6배.
- **월정액 + 월 3만원**: VIP 5가 한 달, VIP 9가 1년 안. 원정 3슬롯·오프라인 +5시간 등 편의가 크게 차이 남.
- **월정액 + 월 10만원**: 모든 편의를 즉시. 그래도 어려움 엔딩은 90일 이상(전투력 미판매).

## 5. 다음 조정 포인트(실제 출시 데이터로)

- 무과금 보석 유입(하루 약 150)이 너무 후하면 활동 상자 보석(20/30/50)부터 줄인다.
- 구세계 금고 천장(200점)과 전설 확률(군용 10%)은 결제 전환·이탈률을 보고 조정. 확률을 바꾸면 화면 공개 문구도 같이 바뀐다(데이터 한 곳).
- 공사 시간 합계 52시간은 '하루 1~2번 접속' 리듬 기준. 체류 시간이 짧으면 Lv6~8 시간을 늘린다.
