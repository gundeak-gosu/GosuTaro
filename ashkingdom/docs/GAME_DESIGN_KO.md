# 잿빛 왕국 (Ashen Kingdom) — 게임 기획서 v1.0

> 핵전쟁으로 멸망한 세계에서 살아남은 한 사람이, 남은 사람들을 모아 새로운 왕국을 세우는 **생존·건국 RPG**.
> 장르 레퍼런스: 생존 크래프팅(야생소년·지구의 마지막 날 류) + 도시 건설(프로스트펑크 류) + 수집형 미니게임.
> **레퍼런스 게임의 이름·캐릭터·아트·레벨을 복제하지 않는 오리지널 IP**입니다.

이 문서의 모든 수치는 `js/data.js`와 1:1로 대응합니다. 수치를 바꾸면 반드시 `npm run balance`로 난이도 곡선을 다시 검증합니다.

## 1. 핵심 재미 루프 — "몇 달, 몇 년을 계속하게 만드는 구조"

장기 플레이는 **겹쳐진 시간 단위의 목표**로 만든다. 어느 순간에 접속해도 "조금만 더"가 있다.

| 주기 | 플레이어가 하는 일 | 보상/긴장 |
|---|---|---|
| 30초 | 채집·사냥·전투 | 재료, 경험치, 데미지 숫자 |
| 5분 | 제작·건설, 게임 속 하루(실제 6분) | 새 도구/시설, 밤의 위협 |
| 30분 | 스토리 장 진행, 원정, 미니게임 | 시네마틱, 새 동료 |
| 하루(실제) | 일일 미션, 올림픽 3회 도전, 영토 전쟁 3회, 광고 보상 | 보석(무과금 재화) |
| 1주(실제) | 습격 방어 주기, 계절 순환(게임 7일=실제 42분), 무료 부활 쿨타임(어려움) | 성 확장 |
| 2주(실제) | **올림픽 시즌** 종료·순위 보상 | 큰 상품, 칭호, 전용 외형 |
| 1~3개월 | 보통 난이도 엔딩, 다른 직업으로 새 생애 | 엔딩 도감, 혈통 |
| 6개월~2년 | 어려움 엔딩, 16엔딩 수집, 세계 재건 100% | 왕관, 명예의 전당 |
| 끝 없음 | 에필로그 "세계 재건 원정"(지역마다 요구치 상승) + 시즌 업데이트 | 라이브 서비스 |

**장기 동기 3축**
1. **혈통**: 오래 살수록·오래 할수록 그 직업 혈통이 강해져 다음 생애가 쉬워진다(로그라이트 메타 성장).
2. **왕국**: 집 → 성으로 눈에 보이게 커지는 기지, 늘어나는 주민, 결혼·자녀·계승(세대 이야기).
3. **수집·경쟁**: 엔딩 16종, 혈통 8직업, 동물·탈것, 올림픽 시즌 칭호.

## 2. 세계관과 스토리

**섬광의 날** — 하늘이 하얗게 타오른 날, 문명이 끝났다. 주인공은 지하 대피소에서 살아남아 잿빛 눈이 내리는 세상으로 나온다.
라디오 너머의 목소리, 굶주린 겨울, 들개의 왕, 철의 도시, 약탈자 '붉은 손', 방사능 강, 정착지 연합을 거쳐
마지막 적 **재의 군주**를 쓰러뜨리고 새로운 왕국을 선포한다. 그 뒤엔 멸망 이전의 모든 땅을 되살리는 끝없는 재건이 이어진다.

## 2.5 하나의 지구 — 모두가 같은 세계의 서로 다른 곳에서 시작

- 게임을 시작하면 **지구의 무작위 육지 한 구역**에 떨어진다. 어디서 시작할지는 아무도 모른다(낙하 지점 공개 연출 + 세계 지도).
- 지구 = 실제 지리(Natural Earth 1:50m 육지 데이터를 0.5° 격자로 내장, `js/earth-data.js`, 43KB). 0.5° 칸을 다시 64×64 구역(약 0.87km)으로 나눠 **육지 구역 약 3억 개** → 1억 명이 시작해도 겹칠 확률이 낮다(테스트로 ≥ 2억 확인). 서버가 있으면 `ashk_regions` 유니크 키로 같은 구역 중복을 막는다(새 생애당 쓰기 1번).
- **같은 좌표 = 같은 시드 = 같은 지형**(마인크래프트 시드처럼). 극지·남극 빙원은 시작 불가.
- 위치가 정하는 것: 생물군계 7종(온대림·열대우림·사바나·사막·초원/스텝·타이가·툰드라), 계절 기온(연평균 ± 연교차, 대륙성 반영, 핵겨울 -4℃), 강수(적도 다우·아열대 사막·아시아 몬순·편서풍), **낮 길이**(고위도 여름은 길고 겨울은 짧음), 계절 이름(열대=건기/우기, 극지=백야/극야), **날씨 11종**(맑음·흐림·비·폭풍우·눈·눈보라·안개·폭염·모래폭풍·잿가루·방사능 폭풍), 지형(모래·눈 타일), 나무 모양, 자원 분포, 야생동물, 가장 가까운 옛 도시.
- **난이도·흐름은 같게**: 지역 고유의 압박(사막=갈증, 툰드라=추위·배고픔)은 살리되
  1. 생존 압박 지수(배고픔+갈증+추위 피해, 사계절·밤낮 평균)를 계산해 배고픔·갈증 소모를 자동 보정 → **어느 지역이든 ±10% 이내**(300개 무작위 지점 테스트),
  2. 지역 생존 준비물(툰드라: 모피 코트 재료, 사막: 물 4병 등),
  3. 어느 지역이든 기지 근처 물웅덩이(오아시스)와 초반 자원 보장,
  4. 극한 기온은 -30~40℃로 제한, 스토리·보스·습격·밸런스 곡선은 전 지역 동일.

| 지역 예 | 군계 | 특징 |
|---|---|---|
| 서울 근교 | 온대림 | 사계절 뚜렷, 핵겨울 영하 |
| 사하라 | 사막 | 갈증 ×1.35, 모래폭풍·폭염, 고철 많고 나무 적음 |
| 아마존·콩고·말레이 | 열대우림 | 비·폭풍우, 나무·약초 풍부, 계절=건기/우기 |
| 시베리아·알래스카 | 타이가 | 침엽수, 연교차 50℃ 이상, 눈 |
| 북극권 | 툰드라 | 눈보라, 백야·극야, 배고픔 ×1.2 |
| 몽골·아르헨티나 | 초원·스텝 | 말·염소, 바람·먼지 |

## 3. 캐릭터

### 3.1 성별·외형
- 남/여 선택. **능력치는 동일, 외형만 다름**(공정성 — 테스트로 검증).
- 기본 상태는 **맨몸(기본 속옷 레이어)**. 입는 옷(머리·몸·다리·발·등)과 손에 든 무기·도구, 타고 있는 탈것이 **그대로 실루엣에 반영**된다.
- [자세히 보기]에서 피부색·머리 모양·머리색 꾸미기(외형만, 능력치 무관).

### 3.2 직업 8종
| 직업 | 패시브 | 혈통 기술(Lv2/5/10/20) | 엔딩 계열 |
|---|---|---|---|
| 🎖️ 군인 | 전투 피해 +20% | 정조준 / 지휘 / 요새화 / 전쟁 영웅 | 강철의 수호왕 ↔ 철혈 군주 |
| 🩺 의사 | 치료 +50%, 방사능 저항 30%, 챕터당 자가 소생 1회 | 응급처치 / 외과의 / 백신 / 기적의 손 | 치유의 군주 ↔ 격리의 지배자 |
| 🔧 기술자 | 건설비 -20%, 내구도 소모 -30% | 정비 / 엔진공 / 포탑 설계 / 건축왕 | 기계 도시의 설계자 ↔ 강철 공장의 주인 |
| 🍳 요리사 | 부패 -25%, 영양 +30% | 저장의 달인 / 잔치 / 미식가 / 풍요 | 풍요의 군주 ↔ 곡창의 독점자 |
| 🔬 연구자 | 연구 +50%, 경험치 +10% | 분석 / 정화학 / 원자로 지식 / 새벽의 학자 | 새벽의 학자왕 ↔ 금지된 지식의 수호자 |
| 🎩 정치인 | 영입 +50%, 사기 +15, 올림픽 상금 +20% | 연설 / 조약 / 세제 개혁 / 국부 | 공화국의 첫 의장 ↔ 종신 총통 |
| 🌾 농부 | 수확 +50%, 길들이기 쉬움 | 녹색 손 / 목축 / 대풍년 / 에덴 | 녹색 대지의 왕 ↔ 대지주 |
| 🛋️ 백수 | 능력치 낮음, 행운 +30%, 경험치 +25% | 운빨 / 뭐든 해봄 / 언더독 / 얼떨결 왕 | 얼떨결에 왕 ↔ 게으른 폭군 |

### 3.3 두 가지 레벨
- **생애 레벨**(최대 60): 이번 생의 경험치. 레벨당 능력치 포인트 2. 죽고 세계가 초기화되면 1부터.
- **혈통 레벨**(직업별, 상한 없음): `floor(sqrt(누적경험치/400))`.
  - **살아 있는 동안에도 실시간으로 쌓인다** → "한 캐릭터로 오래 살수록, 오래 할수록 강해진다".
  - 혈통 2레벨마다 전 능력치 +1(현재 캐릭터에 즉시 적용), 특정 레벨에서 직업 기술 해금.
  - 죽음·계승·엔딩 시 장 보너스(장×300)가 추가 적립.

## 4. 목숨은 하나 — 죽음·부활·계승

사망 원인: 굶주림, 갈증, 저체온, 방사능, 질병, 전투.
사망 시 선택지(코드: `reviveOptions`):

| 수단 | 조건 | 비고 |
|---|---|---|
| 무료 부활 | 쉬움 24h / 보통 72h / 어려움 168h(실제 시간)마다 | 모두에게 공평 |
| 부활권 | 월정액 주 1장, 이벤트 | |
| 소생 키트 | 연구소에서 제작 / 상인 구매 | 게임 내 획득 |
| 의사 동료의 소생술 | 챕터당 1회 | 스토리 동료 활용 |
| 의사 직업 자가 소생 | 챕터당 1회(기적의 손 2회) | 직업 특성 |
| 광고 시청 | 하루 1회, **어려움에선 불가** | |
| 보석 | 챕터 내 횟수마다 비용 증가 (어려움: 300→900→2700) | 지속 과금 지점 |
| **자녀 계승** | 성인이 된 자녀가 있을 때 | 왕국·동료·창고 유지, 레벨 1부터, 혈통 유지 |
| 죽음 수용 | 항상 | 세계 초기화, 혈통 경험치 보존 |

- 부활 페널티: 가방의 **재료** 절반 손실(장비는 유지) → 죽음이 가볍지 않게.
- **보석·부활권·혈통은 계정 귀속**: 캐릭터가 죽어도 결제한 재화는 사라지지 않는다(테스트로 보장).

### 5.1 수치
| 수치 | 감소/증가 | 0 또는 한계일 때 |
|---|---|---|
| ❤️ 체력 | 포만·수분 50↑, 방사능<100, 체온≥0이면 자연 회복 | 사망 |
| 🍗 포만 | 시간당 -3(추위·질병 시 가속) | 시간당 체력 -3 |
| 💧 수분 | 시간당 -4.2(여름 가속) | 시간당 체력 -5 |
| 🌡️ 체감온도 | 계절 + 밤(-8) + 기지(+6+Lv) + 모닥불(+15) + 옷 보온 | 영하면 체력 감소 |
| ☢️ 방사능 | 방사능 지대 시간당 +8 × (1-차단율) | 100↑면 시간당 체력 -4 |
| 🤢 질병 | 생고기·더러운 물·상한 음식 | 시간당 체력 -1, 약초차/구급상자로 치료 |

### 5.2 음식 부패와 보관 (현실감의 핵심)
- 음식마다 **상온에서 완전히 썩기까지의 시간**이 다르다: 생선 16h, 생고기 24h, 우유 30h, 산딸기 40h, 구운 고기 60h, 빵 4일, 달걀 5일, 감자 12.5일, 염장 고기 17.5일, 훈제 육포 25일, 통조림·라면 무기한.
- 신선도 70%↑ 신선 / 30~70% 보통 / 30%↓ **상하기 직전**(영양 60%, 식중독 +35%) / 0% → **썩은 음식**(퇴비 재료로 순환).
- **보관 방식 배율**: 가방 ×1.0 · 나무 상자 ×0.8 · 지하 저장고 ×0.4 · 냉장고 ×0.15(발전기 연료 필요, 정전 시 ×1.0).
- **계절 배율**: 여름 ×1.35, 가을 ×0.9, 핵겨울 ×0.55. 난이도 배율(쉬움 0.75 / 어려움 1.3).
- **가공으로 수명 연장**: 생고기 → 훈제실(육포 25일) / 주방(염장 17.5일, 스튜).
- 요리사 주민은 기지 음식 부패를 1명당 -25%(최대 -50%).
- 주민은 매일 1개씩 **가장 상하기 직전인 음식부터** 먹는다(선입선출) → 보관 관리가 곧 운영 실력.

### 5.3 내구도 (쓰면 닳는다)
- 도구·무기는 **사용 1회당 -1**, 옷은 **입고 있는 3시간마다 -1, 맞을 때 -1**.
- 0이 되면 부서져 사라진다. 작업대에서 수리하면 내구도가 차지만 **최대 내구도 -10%**(현실적 마모, 기술자 '정비'는 예외).

### 5.4 계절·밤
- 게임 하루 = 실제 6분, 계절 = 7일, 1년 = 28일. 봄 → 여름 → 가을 → **핵겨울**(-14℃, 밭 수확 중단).
- 밤(20~6시): 시야 축소, 변이체 출현, 습격.

### 5.5 꺼져 있는 동안(오프라인)
- 캐릭터는 **기지에서 쉬는 상태**: 굶어 죽지 않는다(앱을 껐다고 죽으면 이탈 원인 1위).
- 기지는 최대 8시간분(실제)을 50% 효율로 생산·부패 진행. 습격은 접속 후 다음 날로 미뤄진다.

## 8. 동료·주민·가족

- **스토리 동료 6명**(장 진행으로 합류) + **무작위 생존자**(판잣집 이상, 매일 확률 방문 → 받아들이기/음식만 주기/쫓아내기 = 업보).

  - **아이는 전투·동행·전쟁에 참여하지 않는다**(테스트로 보장).
  - 성인 자녀는 주인공 사망 시 **왕국 계승자**가 된다(세대 플레이).

## 11. 전투·습격·영토 전쟁

- 필드 전투: 근접(사거리 46) / 원거리(탄약 소모, 사거리 220). 피해 = (무기 공격 + 힘×0.8) × 직업·스킬 배율. 방어는 `100/(100+방어×6)`.
- **습격**: 난이도별 주기, 병력 = (40 + 일수×6 + 거점Lv×25) × 적 배율. 기지 안이면 직접 방어(사격전), 아니면 방어 시설 자동 판정.
  - 패배 시 창고 물자 25% 약탈 + 사기 하락. **건물은 부수지 않는다**(복구 노가다 = 이탈 원인).
- **영토 전쟁(비동기 PvP)**: 거점 Lv4부터. 전투력 ±15% 상대의 '방어 기록(스냅샷)'에 도전. 하루 3회.
  상대가 접속해 있을 필요가 없어 **실시간 서버가 필요 없다**.

## 11.5 나라급 · 급수 · 매칭 (`js/matchmaking.js`, 서버 RPC `ashk_join_olympics`)

- **나라급**: 거점 Lv4(목책 요새) + 주민 5명 → '국가' 선포. 이때부터 올림픽·전쟁·급별 순위 참가.

- **전쟁(주변의 비슷한 급, 무작위)**: 같은 급 500km → 1,500km → 4,000km → ±1급 → ±2급(전세계) → 근처 봇. 각 단계에서 가까운 10곳 중 무작위 3곳 제시. 상대는 접속할 필요 없음(방어 기록과 싸움). 하루 3회, 높은 급 상대 승리 시 영토 점수 가산.
- **올림픽(대륙 비율 + 비슷한 급)**: 64개국 조 = 아시아 20 · 유럽 12 · 아프리카 10 · 북미 10 · 남미 7 · 오세아니아 5. 시즌당 1번 조 배정: 같은 급 조의 내 대륙 빈자리 → ±1급 조 → ±2급 조 → 새 조. 빈자리는 같은 급 봇으로 채워 항상 64개국. 봇도 시즌 동안 점점 종목에 참가(초반 불공정 방지).
- **급별 순위**: 같은 급수 안에서 국력 순위·레벨 표시(상위 100, 1시간 캐시).
- **서버 비용**: 국가 카드 한 줄(화면 열 때만, 1시간 1회, 위치는 0.5° 단위로 뭉갬), 조 배정 시즌당 1회, 조원·순위 조회 1시간 캐시. DB 규칙이 급수-국력 불일치·급상승·잦은 갱신·옛 버전을 거부.

## 15. 그래픽과 연출

| 모드 | 용도 | 표현 |
|---|---|---|
| 필드 | 돌아다닐 때 | 탑다운 2D, 야생소년 수준의 가벼운 캐릭터(60fps 우선) |
| 자세히 보기 | 가방·꾸미기 | 같은 레이어를 7배 확대, 그라디언트 음영·얼굴 디테일 |
| 시네마틱 | 장 시작, 결혼, 출산, 계승, 엔딩 | 대형 디테일 렌더 + 역광·비네팅·레터박스·타자기 자막 |

- **페이퍼돌 레이어 순서**(실서비스 Spine 슬롯과 동일): 등(망토/배낭) → 다리(맨다리→바지→신발) → 몸통(맨몸+기본 속옷→상의) → 팔·손 무기 → 머리 → 머리카락 → 모자.
- 부드러운 움직임: 걷기 위상 기반 팔·다리 스윙, 호흡 bob, 카메라 보간, 탈것 갤럽.
- 기지 외형이 레벨마다 바뀐다(말뚝 → 목책 → 돌 성벽 → 탑 → 왕실 깃발).
- 계절·밤·방사능 지대: 눈/재/방사능 입자, 밤 조명(플레이어·모닥불·기지 불빛).
- **실서비스 권장 아트 파이프라인**: Spine 2D 스켈레톤(옷 슬롯 교체로 수백 벌 조합) + 시네마틱은 일러스트(또는 Blender 렌더) 정지화+패럴랙스.
  "특별 이벤트 때 사실적인 모습"은 이 일러스트 레이어로 구현하고, 필드는 가볍게 유지해 저사양 폰에서도 60fps.

## 16. 기술 구조와 서버 비용 최소화

```
[브라우저/PWA 또는 Capacitor 앱]
  ├─ js/systems.js  규칙 엔진(순수 함수, DOM 없음) ← Node에서 테스트·시뮬레이션
  ├─ js/world.js    시드 기반 월드 생성(저장하지 않음)
  ├─ js/render.js   Canvas 2D 렌더(청크 캐시, 이모지 스프라이트 캐시)
  ├─ js/ui.js       DOM 패널
  ├─ localStorage   세이브(무결성 서명) + 저장 코드 내보내기/가져오기
  └─ sw.js          오프라인 캐시(재방문 로딩 ≈ 0초, 트래픽 ≈ 0)
          │  (선택) 하루 몇 번만
          ▼
[Netlify Functions] ──► [Supabase Postgres]
   ashkingdom-save        ashk_saves(클라우드 백업)
   (올림픽/전쟁: 확장)    ashk_olympics(시즌 기록, 서버 재계산 검증)
```

**비용을 낮추는 결정들**
- **실시간 서버 없음**: PvP·올림픽 모두 비동기(스냅샷/기록 대결). WebSocket 서버 0대.
- **월드는 시드로 재생성**: 세이브엔 고갈 노드만 저장 → 세이브 10~30KB(테스트: 풀 성장 상태 < 64KB).
- **로컬 우선 저장**: 서버 저장은 백업용(세션 종료 시 1회 수준). 실패해도 게임 진행 무관.
- **결정적 난수**: 서버는 시드로 점수를 재계산만 하면 되므로 무거운 시뮬레이션 서버가 필요 없다.
- **정적 호스팅 + CDN**: 게임 파일은 전부 정적. 서비스워커 캐시로 재방문 트래픽 거의 0.

**예상 비용(2026년 기준 대략치 — 각 서비스 요금제는 출시 전 반드시 재확인)**
| 규모 | 구성 | 월 비용 |
|---|---|---|
| ~5천 DAU | Netlify 무료 + Supabase 무료 | 0원 |
| ~5만 DAU | Supabase Pro(약 $25) + Netlify 무료/저가 플랜, 클라우드 저장을 클라이언트→Supabase 직접(RLS)으로 함수 호출 절감 | 약 3~5만원 |
| 앱 출시 | Google Play 등록 $25(1회), Apple Developer $99/년 | — |

**속도**: 지형은 16×16 타일 청크를 오프스크린 캔버스에 1회만 그려 재사용, 화면 밖 엔티티 미렌더, devicePixelRatio 최대 2로 제한, 몹 상한(10+장 수).

### 16.1 서버비 0원 운영 규칙 (결과만 보내기 · 접속 총량 줄이기 · 공짜 조작 필터) — `js/net.js`, `docs/supabase_schema.sql`
| 규칙 | 구현 |
|---|---|
| 게임은 전부 기기에서 | 채집·전투·성장·제작 모두 클라이언트. **서버 세이브 없음**(기기 이전 = 저장 코드) |
| 결과 한 줄만 전송 | `ashk_records(user, season, kind) → score` 한 줄 upsert |
| 랭킹 화면 열 때만 전송 | 원정/경기마다 보내지 않음 |
| 안 바뀌면 안 보냄, 바뀌어도 1시간 1회 | 클라이언트 캐시 + DB 트리거(`too frequent`) 이중 차단 |
| 받기 1시간 캐시, 상위 100명, 공지 10개 | `limit=100`, `limit=10` |
| 명예의 전당 | 주간 1위를 pg_cron 으로 영구 기록, 기기에 누적 저장 후 **새 주만** 주 1회 수신 |
| 이름 변경 하루 1회 | 클라이언트 + DB 트리거 |
| 해킹 기록 거르기(비용 0) | RLS(본인 행만 쓰기·삭제 불가) + CHECK(시즌 형식·종목·브래킷) + 트리거(옛 버전 `min_client_ver` 거부, 현재 시즌만, 점수 상한, 비정상 급상승 거부, 최고 기록만 유지) |
| 매일 수동 확인 | `ashk_suspicious` 뷰(브래킷별 상위 1% × 1.3 초과 기록) |
| 변조 세이브 | 서명 불일치 시 온라인 랭킹 전송 자체를 하지 않음 |
| 서버비 폭탄 대비 | Supabase **Spend Cap 켜기 + 사용량 알림**, Netlify 사용량 알림 설정(알림만 오고 멈추진 않으므로 즉시 확인) |

### 16.2 기기 간 이어하기(PC·휴대폰) — `js/sync.js`, `docs/APP_BUILD_KO.md`

## 18. 기획 검토 — 발견된 모순·위험과 해결

요구사항을 그대로 합치면 충돌하는 부분이 있어, 다음처럼 해결했다.

| # | 문제 | 해결 |
|---|---|---|
| 1 | "생명 1개, 죽으면 끝" ↔ "죽어도 레벨이 높아져야" | 생애 레벨(초기화) + **혈통 레벨(영구)** 이원화 |
| 2 | 혈통이 '죽을 때만' 쌓이면, 안 죽는 과금 유저는 혈통이 안 큼 → "오래 살수록 강해진다"와 모순 | **혈통을 살아 있는 동안 실시간 적립**하도록 변경(밸런스 시뮬 단계에서 발견) |
| 3 | "어려움은 과금해야 깬다" ↔ 공정성·법규(P2W 논란) | 과금 = 시간 단축만. 무과금 장기 육성으로도 클리어 가능(시뮬 검증: 2년 내 80%↑) |
| 4 | 시뮬 결과 어려움에서 과금 효과가 미미(434일 vs 522일) → "지속 과금해야 깬다" 불성립 | 월정액 XP +20%, **훈련 교본**(XP +50%, 무과금도 미션 보석으로 구매 가능) 추가 → 264일 vs 407일 |
| 5 | 어려움에서 광고 부활이 매일 가능하면 난이도가 무의미 | 어려움은 광고 부활 불가, 보석 부활 비용 3배씩 증가 |
| 6 | 앱을 꺼 둔 사이 굶어 죽음 = 최대 이탈 원인 | 오프라인 중엔 '기지에서 휴식', 기지만 최대 8시간 진행 |
| 7 | 결제 재화가 캐릭터와 함께 사라지면 환불 분쟁 | 보석·부활권·혈통은 계정 귀속 |
| 8 | "캐릭터는 벗고 있는데" ↔ 앱스토어 연령 등급 | 기본 속옷 레이어(12세 이용가 수준) |
| 9 | 결혼·출산 콘텐츠 등급 | 암시·시네마틱 문장 수준, 노출 없음 |
| 10 | 아이가 전쟁에 참여 | 아이는 전투·동행·전쟁·올림픽 불가(성인 이후만) |
| 11 | 실시간 PvP는 서버비 폭증 | 비동기 스냅샷 대결 |
| 12 | 클라이언트 점수 조작 | 결정적 시드 → 서버 재계산 검증, 세이브 서명(변조 시 경쟁 기능 제한) |
| 13 | 사실적 그래픽 ↔ 저사양 속도 | 3단 LOD(필드 가볍게 / 자세히 / 시네마틱만 고품질) |
| 14 | 습격 패배 시 건물 파괴 → 복구 노가다 | 창고 일부 약탈 + 사기 하락으로 대체 |

### 18.1 테스트가 잡아낸 실제 버그
- 연구소 데이터의 `research: 1`(연구 포인트 의미)이 '선행 연구 필요' 키와 충돌 → **연구소를 영원히 못 짓는 버그**. `researchPts`로 분리.

## 21. 프로토타입의 범위 (정직한 현황)

**구현됨**: 캐릭터 생성(성별·8직업·3난이도), 생존 수치, 계절·밤, 부패·보관, 내구도·수리, 채집, 제작 40여 종, 시설 25종, 거점 8단계(외형 변화), 연구 8종·시대 4단계, 동료·역할·사기·대화·선물·결혼·출산·성장·계승, 무작위 생존자·조우·업보, 동물 8종 길들이기·우리·생산·번식·도축, 탈것 3종(말·자전거·오토바이), 필드 전투, 습격, 최종 보스, 16엔딩, 에필로그 원정, 미니게임 5종, 올림픽 시즌, 비동기 영토 전쟁, 상점·월정액·광고(시뮬레이션)·일일 미션, 저장·오프라인 진행·저장 코드, PWA 오프라인.

**v1.1 추가**: Three.js 3D 필드(지형·그림자·안개·주야·날씨, 관절 휴머노이드 + 옷 레이어, 3D 동물·탈것·성), 3D 자세히 보기/시네마틱, 매 생애 다른 지도(장소·보스 구성은 동일, 위치는 시드별 무작위 + 도로 보장), 던전 보스 4종, 제작 품질 5등급 + 좋은/나쁜 특성 10종(손재주·행운·혈통·시설에 따라 확률 변화), 서버비 0원 네트워크 계층.

**아직 아님(알파에서)**: 실제 결제·광고 SDK 연동(현재 테스트 결제), 실제 다른 유저와의 매칭(현재 같은 브래킷의 결정적 '라이벌'로 대체 — 서버 테이블 스키마는 `docs/supabase_schema.sql`), 사운드, 전문 아트(현재 코드로 그린 벡터 + 이모지), 튜토리얼 연출.

## 2026-11 업데이트 요약
- **속도**: 필드는 기본 '빠른 2D'(60fps). 3D 필드는 설정에서 선택. 이야기 장면·자세히 보기만 3D, 캐릭터 모델은 내 성별만 필요할 때 내려받음.
- **세이브 슬롯 8개**(`storage.js`): 1번 슬롯은 예전 저장 키 그대로.
- **지역 지도**(`js/regions.js`): 고향 + 격자 위 지역들(숲·밀림·초원·사막·설산·타이가·늪·협곡·도시·방사능·사바나). 지역 미션(처치·탐험·채집, 고향은 이야기 2장)을 깨면 이웃 지역이 열림. 가장자리로 걸어가면 넘어감. 안개(탐험한 칸만 밝게)는 지역별 비트맵으로 저장.
- **물**: 깊은 강(통과 불가, 나무 4개로 다리) · 얕은 샛강(느리게 통과) · 옛 도로의 다리.
- **채집**: 맞는 도구가 없으면 한 번 칠 때 진행 0.12~0.25(맨손은 아주 느림). 나뭇가지는 맨손으로 쉽게 → 첫 도구·모닥불.
- **생존**: 체력은 잠잘 때만 회복(침대 100%·침낭 70%·맨땅 40%, 기지 밖은 습격 위험). 날고기·생선·더러운 물은 병 위험. 철광석·숯 → 철괴 → 강철.
- **전투 장비**: 오른손/왼손, 양손 무기, 활통(화살 종류·용량·약 90% 회수), 던지기(R), 무기별 필살기(F), 무기 기술(교본·훈련소), 정화 숫돌로 특성 제거.
- **동물·약탈자**: 길들이기 레벨 표, 동물 탐색(실제 3시간 충전·보석·냄새 미끼), 약탈자 무리 NPC(싸움·통행료·설득).
